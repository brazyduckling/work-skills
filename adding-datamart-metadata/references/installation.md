# Installation

Use these steps to install the skill on a different machine.

## Copilot CLI

1. Clone or download the `work-skills` repo
2. Copy the `adding-datamart-metadata/` folder into:

```text
~/.copilot/skills/
```

Final path:

```text
~/.copilot/skills/adding-datamart-metadata/SKILL.md
```

3. Start a new Copilot session so the skill can be discovered

## Claude Code

1. Clone or download the `work-skills` repo
2. Copy the `adding-datamart-metadata/` folder into:

```text
~/.claude/skills/
```

```text
~/.claude/skills/adding-datamart-metadata/SKILL.md
```

## Optional dependency

If the environment supports installable skills, also install `jet-bq` from the JET-approved skills source so BigQuery inspection can use the approved shared skill.
